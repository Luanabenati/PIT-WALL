# 🏎️💨 DESAFIO PIT WALL — GP DE SÃO PAULO

Projeto desenvolvido como desafio prático do **Sistema Musical**, recriando uma página temática do Grande Prêmio de São Paulo, em Interlagos, utilizando exclusivamente HTML5 e CSS3.

## 🏁 Sobre o projeto

A proposta consiste em desenvolver uma página inspirada no universo da Fórmula 1, destacando o GP de São Paulo por meio de um layout moderno, esportivo e responsivo.

O projeto apresenta:

- **Hero:** destaque principal do GP de São Paulo.
- **Grid de pilotos:** cards com números, nomes e equipes.
- **Classificação:** tabela com posições e pontuações.
- **Ingressos:** informações e formulário de compra.
- **Layout responsivo:** adaptação para computadores e celulares.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## ⚙️ Conceitos aplicados

- `:root` para variáveis e cores das equipes.
- Flexbox para organização dos elementos.
- CSS Grid com `auto-fit` para os cards dos pilotos.
- `form-grid` para o formulário de ingressos.
- `thead` e `tbody` para a tabela de classificação.
- `@media queries` para responsividade.
- Imagens de fundo e elementos visuais inspirados na pista de Interlagos.

## 🎨 Identidade visual

A interface utiliza uma estética esportiva com fundo escuro, detalhes em vermelho, tipografia marcante e elementos inspirados no automobilismo.
